# Bundled Whisper model

`ggml-base.bin` is the multilingual Whisper base model converted for whisper.cpp.

- Source: https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin
- SHA-256: `60ED5BC3DD14EEA856493D334349B405782DDCAF0028D4B5DF4088345FBA2EFE`
- Use: local Vietnamese transcription in Auto Podcast Editor.

`ggml-small.bin` is the multilingual Whisper small model used by the Phase 0.5 benchmark.

- Source: https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
- SHA-256: `1BE3A9B2063867B937E64E2EC7483364A79917E157FA98C5D94B5C1FFFEA987B`
- Use: compare Vietnamese accuracy/performance before selecting the production tier.
